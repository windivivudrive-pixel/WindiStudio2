# Duyệt layout v01 — WindiStudio Dark Interface

## Hướng hình ảnh

- Nền charcoal `#25272b` với lưới mảnh 28px như dark mode của website.
- Typography **SVN Calling Code**, chữ kem `#eeeae0`, headline lớn nhưng giữ tối đa 2–3 dòng.
- Các bước workflow nằm trong cửa sổ retro: viền gần đen, surface `#313338`, title bar cam `#c7815f`.
- Xanh, vàng, hồng và lam chỉ dùng như trạng thái/nhãn phụ; cam là CTA chính.
- Không dùng pixel bird/mascot trong video để tránh rối khung 9:16.

## Nhịp dựng

1. Hook 1,6 giây: chia đôi lời hứa “tự động” và thực tế vận hành.
2. Hai nhịp nhanh liệt kê tốn credit, chờ lâu, voice máy.
3. Reveal Windi rồi đi qua workflow bằng từng cửa sổ/trạng thái hoàn tất.
4. Chậm lại ở đoạn voice để người xem nghe được độ gần gũi.
5. Tăng nhịp ở so sánh thời gian và chốt CTA.

## Bộ cảnh được phép dùng trong kịch bản

| ID | Dùng cho |
| --- | --- |
| `chaos-hook` | Đối lập quảng cáo tự động với thực tế |
| `problem-stack` | Stack nỗi đau/lỗi |
| `windi-reveal` | Reveal sản phẩm |
| `workflow-window` | Chuỗi bước đã duyệt |
| `feature-split` | Tính năng và lợi ích |
| `human-voice` | Chứng minh voice gần gũi |
| `time-proof` | So sánh thời gian/thao tác |
| `fomo-cta` | Chốt lời mời thử |

## Trạng thái

Layout đang chờ duyệt. Chưa viết kịch bản và chưa tạo asset.
