# Khôi phục môi trường dựng

Thư viện node_modules đã được dọn để tiết kiệm ổ đĩa. Code, assets, lockfile và các MP4 được giữ nguyên.

Trong thư mục tập, chạy `npm ci` để khôi phục đúng dependency theo package-lock.json, sau đó `npm run dev` để chỉnh sửa. Cần Node/npm tương thích và mạng để tải thư viện.
