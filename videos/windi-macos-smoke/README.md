# Project thử Windi trên macOS

Đã khởi tạo với Windi Connect 0.5.6, không cần đăng nhập CLI.
Flow và ChatGPT kết nối tại thời điểm kiểm tra. Voice list thành công bằng kết nối
đã có trên máy; chưa phát sinh tạo ảnh/voice ở project này.

Mở folder này trong Codex và nói:
“Dùng Windi làm video về [chủ đề]. Đề xuất idea trước để tôi duyệt.”

Luồng: idea → duyệt layout → duyệt script → tạo ảnh → xử lý watermark → voice → render.
Chưa có idea hoặc script được duyệt trong project thử.
