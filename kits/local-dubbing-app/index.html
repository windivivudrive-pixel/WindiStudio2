Cấu hình máy đề xuất Windows và macOS

Windows: Windows 11 x64, i5 gen 10/Ryzen 5, RAM 16GB, SSD trống 25GB.

Mac: Apple Silicon M1, macOS 14+, RAM 16GB, SSD trống 25GB.

Khuyến nghị RAM 24–32GB và SSD trống 50GB. Đây là cấu hình để bắt đầu thử, chưa phải benchmark bảo đảm tốc độ. Máy 8GB chỉ nên thử Local Decode Quick/Base và 720p. Dịch qua subscription cần internet.

Đã cài ở project khác? Liên kết môi trường có sẵn

Dán đường dẫn project, thư mục môi trường hoặc file Python. Hai công cụ có thể dùng chung hoặc dùng hai môi trường riêng.

Ví dụ macOS: /Users/ban/project-cu · Windows: C:\\DuAn\\project-cu. App tìm trong .venv, venv hoặc env. Với Conda, chọn trực tiếp thư mục môi trường hoặc file Python.
